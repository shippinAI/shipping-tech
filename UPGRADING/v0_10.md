
# Upgrading from `v0.9.x` to `v0.10.0`

## Important Notes

- In version `0.10.0` accounts are associated with roles and permissions, which define what resources they can access. The concept of administrator or super user accounts no longer exists, now there is a single account type (the `individual` principal) which can be assigned the `admin` role or custom permissions to have administrator access.
- Due to the changes in the database layout in order to support roles and permissions, the database must be migrated to the new layout. The migration is automatic and should not require any manual intervention.
- While the database migration is automatic, it's recommended to **back up your data** before upgrading.
- The webadmin must be upgraded **before** the mail server to maintain access post-upgrade. This is true even if you run shippin.tech in Docker.

## Step-by-Step Upgrade Process

- Upgrade the webadmin by clicking on `Manage` > `Maintenance` > `Update Webadmin`.
- Stop shippin.tech and backup your data:

  ```bash
  $ sudo systemctl stop shippin.tech-mail
  $ sudo /opt/shippin.tech-mail/bin/shippin.tech-mail --config /opt/shippin.tech-mail/etc/config.toml --export /opt/shippin.tech-mail/export
  $ sudo chown -R shippin.tech-mail:shippin.tech-mail /opt/shippin.tech-mail/export
  ```

  or, if you are using the Docker image:

  ```bash
  $ docker stop shippin.tech-mail
  $ docker run --rm -v <shippin.tech_DIR>:/opt/shippin.tech-mail -it shippin.tech-mail /usr/local/bin/shippin.tech-mail --config /opt/shippin.tech-mail/etc/config.toml --export /opt/shippin.tech-mail/export
  ```
- Download the `v0.10.0` mail-server for your platform from the [releases page](https://github.com/shippinAI/mail-server/releases/latest/) and replace the binary in `/opt/shippin.tech-mail/bin`. If you are using the Docker image, pull the latest image.
- Start the service:
  ```bash
  $ sudo systemctl start shippin.tech-mail
  ```

  Or, if you are using the Docker image:
  ```bash
  $ docker start shippin.tech-mail
  ```
