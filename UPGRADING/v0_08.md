# Upgrading from `v0.7.3` to `v0.8.0`

Version `0.8.0` includes both performance and security enhancements that require your data to be migrated to a new database layout. Luckily version `0.7.3` includes a migration tool which should make this process much easier than previous upgrades. In addition to the new layout, you will have to change the systemd service file to use the `CAP_NET_BIND_SERVICE` capability.

## Preparation
- Upgrade to version `0.7.3` if you haven't already. If you are on a version previous to `0.7.0`, you will have to do a manual migration of your data using the Command-line Interface.
- Create a directory where your data will be exported to, for example `/opt/shippin.tech-mail/export`.

## Systemd service upgrade (Linux only)
- Stop the `v0.7.3` installation:
  ```bash
  $ sudo systemctl stop shippin.tech-mail
  ```
- Update your systemd file to include the `CAP_NET_BIND_SERVICE` capability. Open the file `/etc/systemd/system/shippin.tech-mail.service` in a text editor and add the following lines under the `[Service]` section:
  ```
  User=shippin.tech-mail
  Group=shippin.tech-mail
  AmbientCapabilities=CAP_NET_BIND_SERVICE
  ```
- Reload the daemon:
  ```bash
  $ systemctl daemon-reload
  ```
- Do not start the service yet.

## Data migration
- Stop shippin.tech and export your data:

  ```bash
  $ sudo systemctl stop shippin.tech-mail
  $ sudo /opt/shippin.tech-mail/bin/shippin.tech-mail --config /opt/shippin.tech-mail/etc/config.toml --export /opt/shippin.tech-mail/export
  $ sudo chown -R shippin.tech-mail:shippin.tech-mail /opt/shippin.tech-mail/export
  ```

  or, if you are using the Docker image:

  ```bash
  $ docker stop shippin.tech-mail
  $ docker run --rm -v <shippin.tech_DIR>:/opt/shippin.tech-mail -it shippin.tech-mail /opt/shippin.tech-mail/bin/shippin.tech-mail --config /opt/shippin.tech-mail/etc/config.toml --export /opt/shippin.tech-mail/export
  ```
- Backup your `v0.7.3` installation:
  - If you are using RocksDB or SQLite, simply rename the `data` directory to `data-backup`, for example:
    ```bash
    $ mv /opt/shippin.tech-mail/data /opt/shippin.tech-mail/data-backup
    $ mkdir /opt/shippin.tech-mail/data
    $ chown shippin.tech-mail:shippin.tech-mail /opt/shippin.tech-mail/data
    ```
  - If you are using PostgreSQL, rename the database and create a blank database with the same name, for example:
    ```sql
    ALTER DATABASE shippin.tech RENAME TO shippin.tech_old; 
    CREATE database shippin.tech;
    ```
  - If you are using MySQL, rename the database and create a blank database with the same name, for example:
    ```sql
    CREATE DATABASE shippin.tech_old;
    RENAME TABLE shippin.tech.b TO shippin.tech_old.b;
    RENAME TABLE shippin.tech.v TO shippin.tech_old.v;
    RENAME TABLE shippin.tech.l TO shippin.tech_old.l;
    RENAME TABLE shippin.tech.i TO shippin.tech_old.i;
    RENAME TABLE shippin.tech.t TO shippin.tech_old.t;
    RENAME TABLE shippin.tech.c TO shippin.tech_old.c;
    DROP DATABASE shippin.tech;
    CREATE database shippin.tech;
    ```
  - If you are using FoundationDB, backup your database and clean the entire key range.
- Download the `v0.8.0` mail-server for your platform from the [releases page](https://github.com/shippinAI/mail-server/releases/latest/) and replace the binary in `/opt/shippin.tech-mail/bin`. If you are using the Docker image, pull the latest image.
- Import your data:

  ```bash
  $ sudo -u shippin.tech-mail /opt/shippin.tech-mail/bin/shippin.tech-mail --config /opt/shippin.tech-mail/etc/config.toml --import /opt/shippin.tech-mail/export
  ```

  or, if you are using the Docker image:
  
  ```bash
  $ docker run --rm -v <shippin.tech_DIR>:/opt/shippin.tech-mail -it shippin.tech-mail /opt/shippin.tech-mail/bin/shippin.tech-mail --config /opt/shippin.tech-mail/etc/config.toml --import /opt/shippin.tech-mail/export
  ```
- Start the service:
  ```bash
  $ sudo systemctl start shippin.tech-mail
  ```

  Or, if you are using the Docker image:
  ```bash
  $ docker start shippin.tech-mail
  ```
