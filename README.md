# shippin.tech

Rust mail and groupware engine (SMTP, IMAP, JMAP, POP3, ManageSieve, CalDAV, CardDAV).

shippin.cloud is later paid hosting of this same binary. Current product work is the Zoho-style client map onto JMAP, CalDAV, and the directory. Collaborative Docs waits until mail, calendar, contacts, and admin exist.
